HOW THE TRAVEL IS BUILT
three phases, one shape. Fall onto the path, run it, reform. The run is identical every time, so there is no pose-dependent jank to chase.
no expansion. The middle phase squeezes the face's own spread down onto the path instead of letting it bloom — river to an eighth, grain to a twentieth.
the near edge leaves first. Order is measured along the direction of travel, so heading left means the left edge dissolves and runs left.
a curve, not a chord. The run is a quadratic through one shared control point, so the whole stream arcs the same way; a slow perpendicular braid on top gives it a current.
trails. Past samples of the same dot, drawn only while it is running. River gets two, grain gets four.
it still lands exactly. Every dot's destination is its real place, so the face is whole the frame the travel ends — no reassembly step to get wrong.
